# Consulting Online Assessment Trainer

This repository now contains a lightweight browser trainer with game mechanics inspired by common consulting online assessments (numerical, verbal, and critical reasoning).

## Included practice games

- **Shortcuts**: pick the lowest-cost route quickly.
- **Grid Lock**: maximize path value with movement constraints.
- **Resemble**: match symbolic patterns accurately.
- **Numbubbles**: form expressions to hit numeric targets.
- **Tally Up**: compare sums under time pressure.
- **Proof It**: detect verbal/grammar errors.
- **Chart Blast**: convert chart-style percentages to profits.
- **Argument Filter**: identify critical reasoning flaws.

## How to run

Open `index.html` directly in a browser.

## What these tests usually evaluate

1. Speed + accuracy tradeoff under pressure.
2. Working memory and rule switching.
3. Numerical estimation before exact calculation.
4. Consistency (few spikes of careless mistakes).
5. Logical rigor: selecting answers based on argument quality, not intuition.

## Weekly drill plan (recommended)

- **Day 1-2:** 20 minutes numerical (Shortcuts, Tally Up, Chart Blast).
- **Day 3:** 20 minutes logic (Grid Lock, Argument Filter).
- **Day 4:** 20 minutes verbal (Proof It + short reading drills outside app).
- **Day 5:** Mixed 30-minute simulation in timed blocks.
- **Day 6:** Error log review (categorize each miss: arithmetic, misread, logic).
- **Day 7:** Light refresh and rest.

## Feedback rubric

- **Strong trajectory:** accuracy above 85% with stable speed.
- **Needs work:** accuracy below 75% or high volatility across sessions.
- **Immediate fix:** if errors are mostly misreads, slow down first 5 seconds to parse constraints before solving.

## Important note

This project is a **practice simulator**, not a replica of any proprietary test content.
